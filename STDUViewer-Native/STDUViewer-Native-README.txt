STDU Reader (Native) — нативный Linux-ридер
===========================================

Файлы:
  STDUViewer-Native-x86_64.AppImage   — готовая программа (943 КБ)
  STDUViewer-Native-source.py         — полный исходный код (Qt/Python)

Это НЕ Wine и не эмуляция. Программа написана заново на PyQt5 и работает
нативно в Linux. Интерфейс повторяет STDU Viewer: меню «Файл / Вид /
Навигация / Инструменты / Справка», левая панель с вкладками «Содержание /
Миниатюры / Закладки» (внизу), панель инструментов, вкладки документов,
серое поле вокруг белой страницы, строка состояния с номером страницы
и масштабом.

Поддерживаемые форматы
----------------------
  PDF          — PyMuPDF (рендер, текст, оглавление, пароли, поиск)
  DjVu         — DjVuLibre (ddjvu / djvused / djvutxt)
  EPUB         — ebooklib (оглавление, картинки)
  FB2, FB2.ZIP — собственный парсер (заголовки, курсив/жирный, картинки)
  MOBI / AZW / AZW3 / PRC / PDB (PalmDoc) — python-mobi
  XPS / OXPS / PS / EPS — конвертация через MuPDF / Ghostscript
  TIFF, PNG, JPEG, GIF, BMP, WebP, ICO, PCX/DCX, PSD, WMF/EMF — Pillow,
                         с резервным конвертером ImageMagick
  JBIG2        — MuPDF / ImageMagick
  CBZ / CBR / ZIP / RAR — как набор изображений (с естественной сортировкой)
  TXT / TCR / HTML / Markdown / RST / DOCX / ODT / RTF — pandoc

Функции (взяты из ресурсов оригинала)
-------------------------------------
  • Режимы просмотра: страницами / разворотами / разворотами с отдельной
    первой страницей
  • Масштаб: 5–500%, «По ширине», «По высоте», «По странице», 100%,
    колесо мыши + Ctrl
  • Процент масштаба показывается в трёх местах: поле «Масштаб: 100%»
    в панели инструментов (редактируется — можно ввести своё значение
    или выбрать пресет из списка), слайдер и число в строке состояния;
    кнопка «1:1» быстро возвращает 100% (как в оригинале),
    кнопка «Увеличить» стоит справа от поля масштаба
  • Повернуть по часовой / против часовой стрелки
  • Боковая панель: вкладка «Недавние документы» ПЕРВАЯ (слева от
    «Содержание»), затем «Содержание», «Миниатюры», «Закладки».
    Недавние файлы сохраняются между запусками и открываются по клику
  • Содержание с быстрым поиском, миниатюры 4 размеров, закладки
    (добавить / удалить / изменить / экспорт / импорт)
  • Поиск по тексту документа, подсветка найденного
  • Во весь экран (F11), скрыть навигационные панели (F6)
  • Экспорт: весь документ набором PNG, весь документ в TXT,
    текущая страница в PNG/JPEG/BMP
  • Свойства документа, пароли на PDF, drag-and-drop файлов,
    открытие файла из аргумента командной строки
  • Значок — оригинальный STDUViewerApp.ico: виден на окне и на панели
    задач (иконка встроена в AppImage; файл .ico рядом — STDUViewerApp.ico)

Запуск
------
  ./STDUViewer-Native-x86_64.AppImage
  ./STDUViewer-Native-x86_64.AppImage книга.pdf
  ./STDUViewer-Native-x86_64.AppImage книга.fb2 книга.epub ...

Зависимости (уже установлены на этой машине)
---------------------------------------------
  python3-pyqt5, python3-lxml, python3-pil, python3-docx,
  djvulibre-bin, pandoc, unrar-free, ghostscript, poppler-utils,
  а также pip-пакеты: pymupdf, ebooklib, mobi

Если перенести AppImage на другую машину, там нужны те же зависимости:
  sudo apt install python3-pyqt5 python3-lxml python3-pil python3-docx \
       djvulibre-bin pandoc unrar-free ghostscript poppler-utils
  python3 -m pip install --break-system-packages pymupdf ebooklib mobi

Исходный код
------------
  STDUViewer-Native-source.py — один файл, можно править и запускать:
  python3 STDUViewer-Native-source.py файл.pdf

Ограничения
-----------
Интерфейс максимально близок, но не байт-в-байт 1:1: это новая реализация,
а не дамп оригинального кода. Редкие форматы (WWF, PSD, DRM-книги) могут
открываться частично или не открываться совсем. Для сравнения: предыдущая
версия STDUViewer-x86_64.AppImage запускает оригинал через Wine и даёт
реальный 1:1 интерфейс.
