STDU Reader (Native) — нативный Linux-ридер
===========================================

Файлы:
  STDUViewer-Native-x86_64.AppImage   — готовая программа (943 КБ)
  STDUViewer-Native-source.py         — полный исходный код (Qt/Python)

Это НЕ Wine и не эмуляция. Программа написана заново на PyQt5 и работает
нативно в Linux. Интерфейс повторяет STDU Viewer: меню «Файл / Вид /
Навигация / Инструменты / Справка», левая панель с вкладками «Содержание /
Миниатюры / Закладки» (внизу), панель инструментов, вкладки документов,
серое поле вокруг белой страницы, строка состояния с номером страницы
и масштабом.

Поддерживаемые форматы
----------------------
  PDF          — PyMuPDF (рендер, текст, оглавление, пароли, поиск)
  DjVu         — DjVuLibre (ddjvu / djvused / djvutxt)
  EPUB         — ebooklib (оглавление, картинки)
  FB2, FB2.ZIP — собственный парсер (заголовки, курсив/жирный, картинки)
  MOBI / AZW / AZW3 / PRC / PDB (PalmDoc) — python-mobi
  XPS / OXPS / PS / EPS — конвертация через MuPDF / Ghostscript
  TIFF, PNG, JPEG, GIF, BMP, WebP, ICO, PCX/DCX, PSD, WMF/EMF — Pillow,
                         с резервным конвертером ImageMagick
  JBIG2        — MuPDF / ImageMagick
  CBZ / CBR / ZIP / RAR — как набор изображений (с естественной сортировкой)
  TXT / TCR / HTML / Markdown / RST / DOCX / ODT / RTF — pandoc

Функции (взяты из ресурсов оригинала)
-------------------------------------
  • Режимы просмотра: страницами / разворотами / разворотами с отдельной
    первой страницей
  • Масштаб: 5–500%, «По ширине», «По высоте», «По странице», 100%,
    колесо мыши + Ctrl
  • Процент масштаба показывается в трёх местах: поле «Масштаб: 100%»
    в панели инструментов (редактируется — можно ввести своё значение
    или выбрать пресет из списка), слайдер и число в строке состояния;
    кнопка «1:1» быстро возвращает 100% (как в оригинале),
    кнопка «Увеличить» стоит справа от поля масштаба
  • Повернуть по часовой / против часовой стрелки
  • Боковая панель: вкладка «Недавние документы» ПЕРВАЯ (слева от
    «Содержание»), затем «Содержание», «Миниатюры», «Закладки».
    Недавние файлы сохраняются между запусками и открываются по клику
  • Содержание с быстрым поиском, миниатюры 4 размеров, закладки
    (добавить / удалить / изменить / экспорт / импорт)
  • Гиперссылки в PDF: переходы на страницы внутри документа, внешние URL,
    ссылки на другие PDF-файлы и локальные файлы. При наведении курсор
    принимает форму «руки», появляется подсказка и подсветка области ссылки;
    ссылки работают в разворотах и при повороте страницы
  • АВТОЗАПУСК: при запуске без аргументов автоматически открывается последний
    документ из недавних (предпочтительно PDF) — и сразу с того места, где вы
    остановились. Если файл передан в аргументе командной строки или через
    desktop-файл, открывается он
  • ЗАПОМИНАНИЕ ПОЗИЦИИ: для каждого документа сохраняются номер страницы,
    место на странице (прокрутка), масштаб, поворот и режим просмотра.
    Файл ~/.local/share/stdu-reader/positions.json; позиция обновляется при
    листании/прокрутке и при закрытии вкладки. Повторное открытие PDF
    возвращает вас на то же место
  • ЛЕВАЯ ПАНЕЛЬ: минимальная ширина уменьшена с 330 до 170 px — её можно
    почти полностью сдвинуть влево. Кнопка «×» на самой панели, кнопка на
    панели инструментов и клавиша F6 скрывают/показывают её; галочка в меню
    «Вид» всегда синхронна с состоянием панели
  • При запуске открыта вкладка «Недавние документы» (первая в боковой панели);
    правый клик по ней — «Открыть», «Удалить из списка», «Очистить недавние
    документы». То же очищение есть в «Файл → Недавние файлы»
  • ЭКСПОРТ: Markdown (.md) и DOCX (Word, .docx) всего документа — в меню
    «Файл» и «Инструменты». Текст и заголовки берутся из всего документа
    (для PDF — с разбивкой по страницам); через pandoc, с резервными
    вариантами html2text и python-docx
  • КОПИРОВАНИЕ ТЕКСТА: выделите текст мышью прямо по странице — он сразу
    попадёт в буфер обмена; Ctrl+C копирует выделение, а без выделения — текст
    текущей страницы. Есть «Копировать текст страницы» и «Копировать весь
    документ» (контекстное меню и меню «Инструменты»). Учитываются масштаб,
    развороты и поворот страницы
  • КАРТИНКИ: правый клик по изображению → «Копировать изображение» (в буфер)
    или «Сохранить изображение как...» (файл на диске в исходном формате).
    Для PNG/TIFF/CBZ/DjVu доступна вся страница. Пункт «Инструменты →
    Сохранить изображение как...» сохраняет картинку под курсором
  • ПОЛЗУНОК НА ВЕСЬ ДОКУМЕНТ: вертикальная полоса прокрутки охватывает все
    страницы PDF, а не только текущую. Перетащите ползунок к нужной странице
    (или щёлкните по дорожке — это ровно одна страница), и документ сразу
    откроется в этом месте; положение внутри страницы тоже сохраняется.
    Горизонтальный ползунок остаётся для страниц, шире окна
  • НЕПРЕРЫВНЫЙ ПРОСМОТР: колесо мыши листает страницы само — дойдя до низа
    страницы, переходит на следующую, до верха — на предыдущую, с плавной
    анимацией и переносом остатка прокрутки. Включён по умолчанию, отключается
    в меню «Вид → Непрерывный просмотр»; переходы по оглавлению/ссылкам всегда
    открывают страницу сверху
  • СГЛАЖИВАНИЕ: PDF рендерится с суперсэмплингом 2× и качественным уменьшением
    при масштабе <150%, поворот и масштабирование — через SmoothTransformation,
    отрисовка разворотов/подсветки — с Antialiasing и SmoothPixmapTransform
  • Поиск по тексту документа с подсветкой всех вхождений на странице;
    переход к следующему/предыдущему совпадению (F3 / Shift+F3, Enter);
    найденный фрагмент автоматически подводится к верху области просмотра
  • Масштабы «По ширине / По высоте / По странице» пересчитываются при
    изменении размера окна, процент в строке состояния всегда актуален
  • Контекстное меню страницы: «Копировать текст страницы»,
    «Копировать адрес ссылки», «Перейти по ссылке»
  • Печать документа (для PDF — все страницы через системный принтер)
  • Во весь экран (F11), скрыть навигационные панели (F6)
  • Экспорт: весь документ набором PNG, весь документ в TXT,
    текущая страница в PNG/JPEG/BMP
  • Свойства документа, пароли на PDF, drag-and-drop файлов,
    открытие файла из аргумента командной строки

`tests/test_dock.py` (6 тестов на ширину и кнопки левой панели),

`tests/test_docscroll.py` (15 тестов на ползунок всего документа):

Запуск
------
  ./STDUViewer-Native-x86_64.AppImage
  ./STDUViewer-Native-x86_64.AppImage книга.pdf
  ./STDUViewer-Native-x86_64.AppImage книга.fb2 книга.epub ...

Зависимости (уже установлены на этой машине)
---------------------------------------------
  python3-pyqt5, python3-lxml, python3-pil, python3-docx,
  djvulibre-bin, pandoc, unrar-free, ghostscript, poppler-utils,
  а также pip-пакеты: pymupdf, ebooklib, mobi

Если перенести AppImage на другую машину, там нужны те же зависимости:
  sudo apt install python3-pyqt5 python3-lxml python3-pil python3-docx \
       djvulibre-bin pandoc unrar-free ghostscript poppler-utils
  python3 -m pip install --break-system-packages pymupdf ebooklib mobi

Исходный код
------------
  STDUViewer-Native-source.py — один файл, можно править и запускать:
  python3 STDUViewer-Native-source.py файл.pdf

Ограничения
-----------
Интерфейс максимально близок, но не байт-в-байт 1:1: это новая реализация,
а не дамп оригинального кода. Редкие форматы (WWF, PSD, DRM-книги) могут
открываться частично или не открываться совсем. Для сравнения: предыдущая
версия STDUViewer-x86_64.AppImage запускает оригинал через Wine и даёт
реальный 1:1 интерфейс.
