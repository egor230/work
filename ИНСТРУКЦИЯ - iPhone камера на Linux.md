# Живое видео с iPhone на этом компьютере (без надписи)

Обновлено: 20 ноября 2026 г., после исправления «замирания» кадра и удаления водяного знака.  
Система: Linux (X11, Cinnamon), iPhone 16 Pro Max с приложением **IP Camera Lite** из российского App Store.

## 0. Самый простой способ — окно с кнопками

Запустите графический пульт (двойным щелчком по файлу в файловом менеджере или командой):

```bash
python3 "/mnt/807EB5FA7EB5E954/soft/Virtual_machine/linux must have/python_linux/work/Пульт камеры.py"
```

Откроется одно окно: **видео прямо внутри** и кнопки под ним. Терминал и отдельный плеер не нужны.

### Кнопки

| Кнопка | Действие |
|---|---|
| **Горизонтально** | Показывать кадр 16:9 (как для обычной веб-камеры) |
| **Вертикально** | Показывать кадр 9:16 |
| **Влево 90 / Вправо 90 / 180** | Повернуть картинку, если она «лежит» на боку |
| **Сброс** | Убрать дополнительный поворот |
| **Надпись УБРАНА / ВИДНА** | Вырезать или, наоборот, показать водяной знак Lite |
| **Растянуть ВКЛ / ВЫКЛ** | ВКЛ — картинка заполняет весь кадр без чёрных полос и в окне, и в Zoom (пропорции искажаются); ВЫКЛ — в окне полосы вырезаются автоматически, а для Zoom остаётся обычное вписание |
| **Звук ВКЛ / ВЫКЛ** | Передавать микрофон iPhone на компьютер. По умолчанию ВКЛ. В Zoom выберите микрофон **iPhone Mic** (или **Монитор iPhone Mic**) |
| **Начать запись / Остановить запись** (или клавиша `r`) | Запись видео в папку `/mnt/807EB5FA7EB5E954/видео`, файлы `.ts` |
| **Перезапустить поток** | Перезапустить соединение (если телефон «залип») |
| **Остановить** | Остановить виртуальную камеру `/dev/video2` |
| **Выход** | Закрыть окно (поток в Zoom это не мешает) |

После нажатия любой кнопки поток автоматически перезапускается с новыми параметрами — видео продолжает идти в том же окне. Если лицо видно боком — нажмите **Влево 90** или **Вправо 90**.

Окно просмотра само подстраивается под формат кадра: при **Вертикально** оно становится уже и выше, при **Горизонтально** — шире и ниже. Тёмные поля внутри видео автоматически вырезаются, поэтому картинка занимает всё отведённое место. Если же поля видны в Zoom/Meet, нажмите **Растянуть ВКЛ**.

### Звук и автоподключение

- **Звук включён по умолчанию.** Приложение отдаёт поток `/live.flv`, в котором есть и видео H.264, и аудио AAC. Звук направляется в виртуальный микрофон **iPhone Mic** (модуль `module-null-sink` PulseAudio/PipeWire). В Zoom/Meet выберите этот микрофон в списке устройств.
- **Подключение полностью автоматическое.** При запуске пульт сам находит iPhone по адресу `192.168.0.34:8081`. Если IP изменился — сканирует подсеть через `nmap` и находит телефон по заголовку `Server: IP Camera for iOS`. Приложение на телефоне должно быть открыто.
- **Запись сохраняется** в `/mnt/807EB5FA7EB5E954/видео` в формате `.ts` — такой файл остаётся воспроизводимым, даже если запись остановить резко. Проверено: записанный файл открывается и имеет корректную длительность.
- **Настройки сохраняются рядом с программой** в файле `camera_settings.json` (в той же папке `python_linux/work`). Запоминаются: расположение кадра, поворот, надпись, растяжение и звук. Окно можно менять размером — оно стартует точно по содержимому и при необходимости растягивается.

Терминальный скрипт `Показать видео с iPhone.sh` остался как запасной вариант (см. §3).

## 1. Что работает сейчас

- Видео с iPhone отображается в **отдельном окне плеера** на экране ПК.
- Водяной знак Lite-версии (дата, «BAT:…», «Powered by IP Camera Lite for iOS», строка про две камеры) **вырезан на стороне ПК** — в кадре его нет.
- Одновременно создана виртуальная камера **`/dev/video2` («iPhone Cam»)** для Zoom / Meet / OBS — тоже без надписи.

Схема:

```
iPhone (IP Camera Lite, MJPEG :8081)
        │  один-единственный клиент
        ▼
ffmpeg (вырезает надпись, поворачивает кадр)
        ├──> /dev/video2 «iPhone Cam»  ──> Zoom / OBS / Meet
        └──> ffplay                     ──> окно с видео на экране
```

### Проверенные параметры

| Параметр | Значение |
|---|---|
| IP iPhone | `192.168.0.34` (может меняться — см. §7) |
| Порт HTTP | `8081` |
| Логин / пароль | `admin` / `admin` |
| Поток | MJPEG, 1440×1080, 25 fps |
| Виртуальная камера | `/dev/video2`, имя `iPhone Cam` |
| Фильтр удаления надписи | `crop=475:233:907:165,transpose=2,scale=-2:720,pad=1280:720:(ow-iw)/2:(oh-ih)/2:black,format=yuyv422` |

## 4. Почему раньше картинка была статичной

Приложение IP Camera Lite **не умеет отдавать один и тот же MJPEG-поток двум клиентам одновременно**. Когда были запущены и `ffmpeg` (мост), и `ffplay` (просмотр) — телефон залипал и показывал один и тот же кадр.

Исправление: по умолчанию поток с телефона читает **только `ffmpeg`**. Он пишет кадры в `/dev/video2`, а плеер уже смотрит это виртуальное устройство камеры. Проверено: два снимка с интервалом 4 секунды различаются — видео действительно живое.

## 5. Как убрать надпись

Бесплатная Lite добавляет водяной знак прямо в пиксели кадра. Убрать его можно двумя способами:

1. **На ПК (сейчас включено по умолчанию).** Скрипт обрезает область с видео ниже строки с текстом, поворачивает её и вписывает в кадр 1280×720. Текст исчезает, артефактов нет (в отличие от «замазывания» фильтром `delogo`, которое оставляет полосу).
2. **Купить IP Camera Pro** (249 ₽) — надписи нет в самом источнике. Ссылка: https://apps.apple.com/ru/app/ip-camera-pro/id990605467

Если вы поменяете настройки на телефоне (выключите Multi Cam и будете держать его горизонтально), фиксированная обрезка станет неверной. Тогда запустите без неё:

```bash
CROP=off "./IP Camera Lite - iPhone webcam.sh" start
```

и перезапустите просмотр. Поток станет полноэкранным, а надпись нужно будет убирать уже покупкой Pro.

## 7. Что сделать на телефоне для лучшей картинки

Сейчас телефон держится вертикально и включён режим **Multi Cam** («Камера с задним телеобъективом + Камера на передней панели»), поэтому видео лежит маленьким прямоугольником в правом верхнем углу. На ПК мы его вырезали и повернули.

Чтобы получить сразу нормальный полноэкранный поток:

1. Откройте **IP Camera Lite** → `Settings`.
2. Выключите **Multi Cam / PIP**, выберите **Front Camera**.
3. Убедитесь, что включён **HTTP Server** (порт 8081).
4. Держите iPhone **горизонтально** и снимите блокировку поворота экрана.
5. Не сворачивайте приложение во время звонка — iOS замораживает камеру в фоне.

## 8. Диагностика

```bash
# Код ответа потока (должен быть 200; поток бесконечный, поэтому таймаут — норма)
curl -s -o /dev/null -w '%{http_code}\n' -m 2 -u admin:admin http://192.168.0.34:8081/video

# Имя виртуальной камеры
cat /sys/class/video4linux/video2/name

# Процессы
pgrep -a -f '^ffmpeg'
pgrep -a ffplay

# Последние ошибки моста
tail -20 /tmp/opencode/iphone-cam/ffmpeg.log
```

### Таблица неполадок

| Симптом | Решение |
|---|---|
| Картинка снова замерла | Кто-то второй подключился к `:8081`. Закройте лишние плееры и перезапустите скрипт просмотра. |
| Текст появился снова | Вы включали `CROP=off` или меняли настройки телефона. Перезапустите мост без `CROP=off`. |
| «Телефон не отвечает, ищу…» | Откройте IP Camera Lite на телефоне; проверьте, что ПК и телефон в одной Wi‑Fi сети. |
| IP телефона изменился | `IPHONE_IP=192.168.1.50 ./"Показать видео с iPhone.sh"` |
| В Zoom нет «iPhone Cam» | Запустите мост и перезапустите Zoom. Если Linux в VM — сеть режимом **Bridge**. |
| `Not a video capture device` | Нормально, когда нет активного источника; запустите мост. |
| Нет звука | Поток `/video` только видео; используйте микрофон ПК. |
| `deprecated pixel format` в логе | Безвредно. |
