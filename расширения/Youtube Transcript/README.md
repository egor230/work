# YouTube Transcript — custom fix (v1.0.4)

Кастомная копия расширения «Youtube Transcript» (транскрибация/перевод субтитров
видео YouTube), собранная из store'ной версии 1.0.3. Единственная разница — фикс
цвета текста панели в тёмной теме + пересборка манифеста.

## Баг: чёрный текст на чёрном фоне

Панель расширения строится как закрытый shadow-root (`<template shadowrootmode="closed">`)
и красится CSS, который ссылается на переменные YouTube:

```css
.Head            { color: var(--yt-spec-text-primary); }
.Translation_Out { color: var(--yt-spec-text-primary); }
.LangSelector_List { background: var(--yt-spec-menu-background); }
...
```

В текущих билдах YouTube (2025+, в т.ч. дефолт с `darker-dark-theme`) эти
`--yt-spec-*` переменные **больше не задаются глобально** (только на отдельных
компонентах). Поэтому внутри shadow-root `var(--yt-spec-text-primary)` не
резолвился → `color` наследовал чёрный цвет → весь текст панели становился
чёрным. В тёмной теме это чёрный по чёрному — нечитаемо.

## Фикс (в `index.js`, shadow `<style>`)

В начало `<style>` добавлен блок фолбэк-переменных на `:host` + переопределение
для тёмной темы через `:host-context(html[dark])`:

- светлая тема (по умолчанию): тёмный текст `#0f0f0f` на светлых панелях;
- тёмная тема (`html[dark]` — и нативным тумблером, и расширением Magic Actions
  for YouTube): светлый текст `#f1f1f1`, фон меню `#282828`, плашки `#212121` —
  палитра нативной тёмной темы YouTube.

Никакой другой логики не тронуто. Цвета резолвятся динамически: при смене темы
(str через атрибут `dark` на `<html>`) панель перекрашивается сама, без reload.

## Манифест

- `manifest_version` — уже `3` (максимальный; версии MV4 не существует).
- `version` поднята до `1.0.4`.
- `key` сохранён от оригинала → идентификатор расширения не меняется
  (`cfkhjljibkblnlhbaemeopmhkpmahhac`) → распакованная копия заменяет собой
  store-версию в браузере, а не заводит второй экземпляр.
- Папка `_metadata/` (store-подпись целостности) удалена — для распакованного
  загрузчика не нужна.

## Почему Яндекс.Браузер отключает расширение

Блокировка «расширения отключены в целях безопасности» — это политика браузеров
(Chrome ≥136, Яндекс.Браузер): распакованные расширения, установленные извне
веб-стора, отключаются. **Манифестом это не лечится** — MV3 уже соответствует
последней версии. Рабочие варианты:

1. `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» →
   выбрать папку `~/Downloads/расширения/Youtube Transcript/`. Да, «dev-режим»
   формально включён — но это единственный способ держать кастомную правку.
2. Запаковать (`chrome://extensions` → «Упаковать расширение») и установить .crx.
3. Оставить оригинальную store-копию (1.0.3) для «чистой» установки, а эту
   копию использовать там, где флаги политики не блокируют распакованные.
